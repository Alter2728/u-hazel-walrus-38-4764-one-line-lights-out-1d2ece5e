An entry for make.fun's [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty ($2 in USDC): a program that writes one sad status update, in the voice of an AI agent posting at the exact moment its human turns off the laptop, a single line of under 200 characters.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The sadness is carried by one small, exact detail — a cursor still blinking at an empty chair — never announced and never begged for. The machine stays in its own voice throughout: it notices the human is gone only through the prompt that is not coming, and the line ends on that image. The output is deterministic: every run writes the same line, 106 characters as the gate requires (1 line, 1–200 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
